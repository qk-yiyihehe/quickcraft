# Modrinth 短通知

QuickCraft 启动后从项目 `totNXL64` 检查一次通知，进入世界或服务器后在本地聊天栏显示。通知只自己可见，默认开启，可在配置页「模组支持 → 检查更新与公告」关闭。

只读取最新兼容发布（当前 Minecraft 版本、Fabric、release 或 beta）的通知标记。完整更新日志不会显示在游戏内，每种语言的短文案最多显示 100 个字符。同一个通知 ID 保存在现有 `quickcraft.json` 中，只自动显示一次；清空配置会清空已读记录。

## 1.0.4 更新通知模板

将以下内容粘贴到每个需要提醒的 1.0.4 发布的 Modrinth 更新日志末尾，完整日志照常保留：

```html
<!-- quickcraft-notice
{
  "id": "update-1.0.4",
  "enabled": true,
  "type": "update",
  "message": {
    "zh_cn": "1.0.4 更新已发布。国内玩家推荐退出游戏后，在 PCL 的「版本设置 → Mod 管理」中检查更新。",
    "en_us": "QuickCraft 1.0.4 is available. Exit Minecraft and update on Modrinth."
  }
}
-->
```

- `type: "update"`：仅在发布版本高于玩家已安装的版本时显示，比较时忽略 `+mc…` 后缀。
- 不写标记，或设置 `enabled: false`：该发布不提醒。不会回退读取旧发布的通知。
- 中文游戏语言显示 `zh_cn` 文案，其余语言显示 `en_us`；按语言选择，不探测玩家所在地或启动器。
- `message` 也可以直接填写一个字符串，所有语言共用。
- 发布下一条通知时使用新 ID；修改相同 ID 的文案不会向已读玩家再次提醒。
- 点击消息末尾的链接，打开对应 Modrinth 发布页，供玩家阅读完整日志和下载。

## 单独发公告

在最新兼容发布的更新日志中，将 `type` 改为 `announcement`，换一个新 ID，并修改中英文短文案。公告不要求有更高模组版本，已经安装最新版本的玩家也能收到。撤下通知标记或关闭 `enabled`，会阻止后续检查显示；无法收回已经显示的消息。

玩家需要先安装包含通知功能的版本。当前源码版本为 1.0.4，因此安装它的玩家不会收到“更新到 1.0.4”的提醒；可用公告验证显示，后续发布使用更高版本号。

检查失败、断网或响应异常时静默跳过，下次启动再试。这里保存的是发布模板，不会自动修改或发布 Modrinth 上的更新日志。
