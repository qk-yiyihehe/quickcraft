# QuickCraft

适用于 Minecraft 1.21-1.21.1 的 Fabric 客户端便捷操作与 Litematica 辅助模组。

> 当前项目处于开发阶段。功能、配置和兼容性仍可能调整，请在备份存档后使用。

## 功能

- 合成辅助：工作台、背包、切石机和铁砧的快捷操作。
- 容器工具：快速转移、整理、丢弃、交易、回存、复制和清空等操作。
- 投影辅助：Litematica 原理图预览、容器材料统计、校验与填充功能。

## 环境

- Minecraft 1.21-1.21.1
- Fabric Loader 与 Fabric API
- MaLiLib
- Litematica（使用投影辅助功能时需要）

## 开发

项目使用 Java 21。Windows 下可执行：

```powershell
.\gradlew.bat build
```
